# 🌦️ RealTime Weather App (iOS)

An elegant **iOS Weather Application** built using **Swift** and **Xcode**, inspired by Apple’s native Weather app.  
This app provides **real-time weather updates**, **dynamic animations**, **saved locations**, and **map-based tourist attractions** for each searched city.

---

## ✨ Features

- 🌍 **Real-time Weather Updates**  
  Displays live temperature, conditions, and forecasts for user-searched locations.

- 🎬 **Dynamic Animations**  
  Beautiful real-time animations that change based on weather conditions (rain, clouds, sun, etc.).

- 📍 **Add / Remove Locations**  
  Users can **save favorite cities** and remove them anytime.

- 🗺️ **Tourist Attraction Finder**  
  Integrated **Map View** displays popular attractions for the selected city.

- 🧭 **Current Location Support**  
  Automatically fetches weather based on the user’s current location.

## 🚀 Getting Started

### Prerequisites
- macOS with **Xcode 15+**
- Swift 5.9 or above
- An API key from [OpenWeatherMap](https://openweathermap.org/api)

### Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/RealTimeWeatherApp.git

2. Open the project in Xcode.

3. Add your API key to WeatherService.swift.

4. Run the app on a simulator or real device.
